# 입력 CSV 작성법 (학생용)

CSV를 만드는 방법은 두 가지다. **방법 1을 권장한다.** 단위 환산을 손으로 하다가 생기는 실수를 막을 수 있다.

| 방법 | 학생이 입력하는 것 | 파일 |
|---|---|---|
| **1. 원자료 입력 → 자동 변환** | 시편 치수, 저울값, ICP 농도, 부피, 희석배수 | [`examples/raw_lab_data_example.csv`](../examples/raw_lab_data_example.csv) |
| 2. 계산값 직접 입력 | 면적(cm²), Co·Ni 질량(µg) | [`templates/template.csv`](../templates/template.csv), [`examples/example_data.csv`](../examples/example_data.csv) |

```bash
python prepare_input.py examples/raw_lab_data_example.csv -o my_input.csv   # 원자료 → 입력 CSV
python df_calc.py my_input.csv                                              # DF 계산
```

## 1. 원자료 CSV의 열 (방법 1)

| 열 | 단위 | 적는 값 | 해당 그룹 |
|---|---|---|---|
| `sample_id` | — | 시편 번호 (A-1, B-2 …) | 전부 |
| `group` | — | A, L, B, C, D, E, F | 전부 |
| `length_mm`, `width_mm`, `thickness_mm` | mm | 버니어캘리퍼스 측정값 | 전부 |
| `mass_before_mg`, `mass_after_mg` | mg | **분석용 용해** 직전과 직후의 시편 질량 | A, B, C, D, E |
| `volume_mL` | mL | 용해액을 정용한 최종 부피 (L은 제염액 전체 부피) | 전부 |
| `dilution` | 배 | ICP 측정 전에 추가로 희석한 배수. 희석하지 않았으면 1 | 전부 |
| `Co_mgL`, `Ni_mgL` | mg/L (= ppm) | **ICP 화면에 나온 농도 그대로** (희석 후 용액 기준) | 전부 |
| `Co_blank_mgL`, `Ni_blank_mgL` | mg/L | 시약 블랭크(시편 없이 같은 산·같은 부피)의 농도 | 전부 |
| `Co_RSD_pct`, `Ni_RSD_pct` | % | ICP 반복 측정(보통 3회)의 RSD | 전부 (없으면 비움) |
| `crud_before_mg`, `crud_after_mg` | mg | crud를 만들기 전과 후의 시편 질량 | A |
| `spike_conc_mgL`, `spike_vol_uL` | mg/L, µL | 첨가한 Co 표준용액의 농도와 부피 | D |
| `note` | — | 메모 (쉼표 금지) | — |

- 측면을 마스킹했으면 면적은 앞뒤 양면(2·L·W)으로 계산된다.
- 측면까지 노출했으면 `--area-mode all` 옵션을 붙인다.
- 면적을 따로 쟀으면 `area_cm2` 열에 직접 넣어도 된다. 이 값이 치수보다 우선한다.

## 2. 손계산 예시 — 시편 B-1 한 줄

| 원자료 | 값 |
|---|---|
| 치수 | 20.00 × 20.00 × 1.00 mm, 측면 마스킹 |
| 표면 용해 전 → 후 질량 | 3034.08 mg → 3028.45 mg |
| 용해액 정용 부피 | 25 mL, 추가 희석 없음 (1배) |
| ICP 측정값 | Co 0.3522 mg/L, Ni 19.74 mg/L (RSD 각 2%) |
| 시약 블랭크 | Co 0.0005 mg/L, Ni 0.0020 mg/L |

| 입력 CSV 열 | 계산 | 결과 |
|---|---|---|
| `area_cm2` | 2 × 20 × 20 mm² = 800 mm² = **8.00 cm²** | 8.0 |
| `dissolved_mass_mg` | 3034.08 − 3028.45 | 5.63 |
| `Co_ug` | (0.3522 − 0.0005) mg/L × 1 × 25 mL | **8.79 µg** |
| `Ni_ug` | (19.74 − 0.0020) mg/L × 1 × 25 mL | 493.5 µg |
| `u_Co_ug` | 8.79 × 2% | 0.176 µg |
| (참고) 용해 층 두께 | 5.63 mg ÷ (7.9 g/cm³ × 8.0 cm²) | 약 0.89 µm |

> **단위 요령:** mg/L × mL = µg 이다. 그래서 `Co_ug` = (농도 − 블랭크) × 희석배수 × 부피(mL)로 계산하면 된다.
> 스파이크는 mg/L × µL = ng 이므로 1000으로 나눠 µg로 바꾼다. 예: 100 mg/L × 80 µL = 8,000 ng = **8.0 µg**.

## 3. 그룹별 체크

| 그룹 | 무엇을 녹이나 | 꼭 넣을 값 |
|---|---|---|
| A | 제염 전 시편의 **산화막만** | crud 전후 질량, 용해 전후 질량 |
| L | 제염액 (시편을 녹이지 않음) | 제염액 전체 부피, 희석배수 |
| B | 제염 후 시편 표면 **~1 µm** | 용해 전후 질량 |
| C | crud 없는 모재 → B와 **똑같이** 제염하고 똑같이 용해 | 용해 전후 질량 (**5개 이상**) |
| D | B와 같은 제염 시편에 Co 스파이크를 넣은 뒤 용해 | 스파이크 농도·부피 |
| E | 제염 시간을 줄인 시편, 표면 용해 | 용해 전후 질량 |

## 4. 저장할 때

- Excel에서 작성했으면 **다른 이름으로 저장 → "CSV UTF-8(쉼표로 분리)"**를 고른다. 그냥 "CSV"로 저장하면 한글이 깨진다.
- 첫 줄(열 이름)은 바꾸지 않는다. 열 순서는 바뀌어도 된다.
- 숫자에 **단위나 천 단위 쉼표를 넣지 않는다.** `1,039` (✗) → `1039` (○)
- 빈 칸은 비워 둔다. 0이나 "-"를 넣지 않는다.
- `#`으로 시작하는 줄은 주석으로 무시된다.

## 5. 자주 하는 실수

| 실수 | 증상 | 바로잡기 |
|---|---|---|
| ICP 농도(mg/L)를 `Co_ug` 칸에 그대로 넣음 | DF가 터무니없이 작거나 큼 | 방법 1을 쓰거나, 농도 × 부피로 환산 |
| 희석배수 누락 | A0와 L의 값이 크게 어긋남 (방법 간 일치 불합격) | `dilution` 확인 |
| 시약 블랭크 미차감 | 블랭크 평균이 0에서 벗어남 | `Co_blank_mgL` 입력 |
| 시편 전체를 녹인 데이터 입력 | 층 두께가 수백 µm로 표시되고 경고 발생 | 표면 ~1 µm만 다시 용해 |
| 용해 전후 질량을 뒤바꿔 입력 | 질량차 음수 경고 | before > after 인지 확인 |
| C와 B의 용해 조건이 다름 | r이 맞지 않아 B에서 가짜 검출 | 산 종류·온도·시간을 동일하게 |
