# Co 도핑 모의 crud 표면제염 — DF 정량평가 지침 (학생용)

작성: 이종현 교수 연구실 / 2026-11
대상: STS 모재 + 마그네타이트 crud(Co ≈ 5,000 ppm 도핑) 모의 폐기물의 표면제염 시험

---

## 0. 왜 이 지침이 필요한가

- crud 막은 약 5 µm로 얇다. 그래서 시편을 **통째로 녹여 ICP 분석**하면, crud의 Co 질량이 모재(벌크) Co 질량에 묻힌다. 그 결과 신호가 ICP 오차 수준으로 떨어지고, **음의 DF**까지 나온다.
  - 예: 두께 1 mm 시편의 양면에 crud 5 µm → crud 질량은 시편의 약 0.66%. crud의 Co 기여는 모재 Co의 약 2% 수준이다.
- 제염 후에는 crud가 완전히 제거되고 모재도 약 100 µm 깎인다. 그래서 잔류 오염이 "없다"고 보는 것이 맞다. 그러나 **"오염도 0"은 정량 결과가 아니다.**
- 따라서 다음 순서로 결과를 제시한다.
  1. 잔류 Co를 **검출 한계 이론(Currie 1968, ISO 11929)**으로 평가한다.
  2. 결과를 "검출 한계 이하 → **DF ≥ 하한값 (95% 신뢰)**" 형태로 보고한다.

> 핵심 원칙
> 1. **시편 전체 용해 금지.** crud만 측정하거나 표면의 얇은 층만 측정한다.
> 2. 모재에서 온 Co는 **Co/Ni 비(r)**로 뺀다.
> 3. 미검출이면 0이 아니라 **검출 한계(L_D)**를 써서 DF 하한을 계산한다.
> 4. 블랭크·스파이크·양성대조로 방법의 판별력을 **입증**한다.

---

## 1. 시편 구성 (같은 모재 히트, 같은 배치로 제작)

| 구분 | 내용 | 최소 수량 | 목적 |
|---|---|---|---|
| A. 제염 전 기준 시편 | crud 생성 + Co 도핑, 제염하지 않음 | 3 | A₀(초기 crud Co) 측정 |
| B. 제염 시편 | crud 생성 + Co 도핑 → 표준 제염 | 3 이상 | 잔류 Co 평가 |
| C. 공정 블랭크 | crud 없는 모재 → B와 동일 제염 → 동일 분석 | 5 이상 | r, σ₀ 결정 |
| D. 스파이크 시편 | B 시편 표면에 Co 표준용액을 L_D의 2~5배 첨가 → 동일 분석 | 2 | 회수율(검출 능력) 입증 |
| E. 양성대조 | crud 시편을 **불완전 제염**(시간 단축) → 동일 분석 | 2 | 잔류가 있으면 검출됨을 입증 |
| F. 모재 원소재 | crud·제염 없는 모재 전체 용해 | 3 | 모재 Co, Ni 함량 참고값 |

- 모든 시편은 **양면 면적(cm²)**을 측정해 기록한다. 측면은 마스킹하거나 면적에 포함한다.
- 모든 질량은 0.01 mg 저울로 측정한다. crud 생성 전, crud 생성 후, 제염 후 질량을 모두 기록한다.

## 2. 측정 절차

### 2.1 제염 전 crud의 Co, A₀ (µg/cm²) — 독립적인 방법 2가지 이상

**방법 a (권장): 산화막 선택 용해 (A 시편)**
- 모재는 거의 녹이지 않고 산화막만 녹이는 용액을 쓴다.
  - 예: 옥살산 + 아스코르브산, 또는 부식억제제를 넣은 묽은 HCl
  - 조건(농도·온도·시간)은 사전시험으로 정하고 기록한다.
- 용해액의 Co, Ni, Fe를 ICP로 분석한다.
- 녹아 나온 모재 몫은 2.3절의 r로 보정한다.

```
A₀ = (Co_용해액 − r · Ni_용해액) / 면적
```

**방법 b: crud 질량 × Co 농도**

```
A₀ = (m_crud생성후 − m_crud생성전) / 면적 × w_Co,crud
```

- w_Co,crud는 방법 a의 용해액 조성에서 구한 crud 내 Co 질량분율이다.

**방법 c (확인용): 제염액 물질수지 (B 시편의 제염액)**

```
A₀,c = (Co_제염액 − r · Ni_제염액) / 면적
```

- 모재 100 µm가 함께 녹으므로 crud Co는 제염액 Co의 약 10%에 불과하다. 불확도가 크다(약 25~30%).
- 그래서 **확인용**으로만 쓴다.
- a·b·c 결과가 불확도 범위에서 일치하는지 표로 제시한다.

### 2.2 제염 후 잔류 Co (B 시편) — 표면의 얇은 층만 분석

- 제염 후 시편 표면을 **약 1 µm만** 녹인다.
  - 예: 묽은 산(HCl 또는 왕수 희석액)에 짧게 침지한다.
  - 녹인 두께는 침지 전후 질량차로 구한다: `두께 = Δm / (ρ_STS · 면적)`, ρ_STS = 7.9 g/cm³
- **같은 조건**을 C(블랭크), D(스파이크), E(양성대조) 시편에도 똑같이 적용한다.
- 용해액의 Co와 Ni를 분석한다.
  - ICP-MS를 우선 쓰고, 없으면 ICP-OES를 쓴다.
  - 내부표준(Y 또는 In)을 넣는다.
  - 검량선은 Fe 매트릭스를 맞춘 표준으로 만든다.
  - ICP-OES로 측정할 때는 Co 228.616 nm의 Fe 간섭을 보정한다.
- **분석 층이 얇을수록 검출 한계가 낮아진다.** 함께 녹는 모재 Co가 곧 배경이기 때문이다. 10 µm 이상 녹이지 말 것.

### 2.3 모재 Co/Ni 비 r (C 시편)

- C 시편(공정 블랭크)에 2.2절과 똑같이 표면을 용해해서 측정한다.

```
r = Co_C / Ni_C        (시편별로 구한 뒤 평균 r̄, 표준편차 s_r)
```

- **반드시 같은 히트의 모재로 제염까지 거친 블랭크에서** r을 구한다. Ni가 우선 용해되는 효과 등이 자동으로 상쇄된다.
- 시험한 강종이 316 계열이면 Mo를 추적 원소로 써서 교차 확인할 수 있다.

## 3. 계산 방법

### 3.1 과잉 Co (모재에서 온 Co를 뺀 값)

각 시편 i에 대해 다음을 계산한다.

```
x_i = (Co_i − r̄ · Ni_i) / 면적_i          [µg/cm²]
```

- **음수가 나와도 그대로 기록한다.** 0으로 잘라내지 않는다. 음수는 블랭크와 차이가 없다는 뜻일 뿐이다.

### 3.2 불확도 전파 (GUM)

```
u(x)² = [u(Co)² + r̄² · u(Ni)² + Ni² · u(r)²] / 면적²
```

- u(Co), u(Ni): ICP 반복 측정 표준편차. 검량선 불확도를 포함한다.
- u(r) = s_r. 블랭크 시편 사이의 표준편차다.
- 실제로는 **u(r) 항이 지배적**인 경우가 많다. 블랭크 수를 늘리면 줄어든다.

### 3.3 결정 한계와 검출 한계 (Currie / ISO 11929, α = β = 0.05)

σ₀는 순신호가 0일 때의 표준불확도다. **C 시편 x 값들의 표준편차**로 구하거나, 3.2절의 식에 블랭크 값을 넣어 구한다.

| 기준 | 식 | 판정 |
|---|---|---|
| 결정 한계 | L_C = 1.645 · σ₀ | x > L_C 이면 "검출" |
| 검출 한계 | L_D = 3.29 · σ₀ (블랭크 수가 적으면 t값 사용) | 이만큼 남아 있으면 95% 확률로 검출됨 |
| 정량 한계 | L_Q = 10 · σ₀ | 이 이상일 때만 정량값으로 보고 |

- 블랭크 수 n이 작으면 1.645 대신 단측 t값 t(0.95, n−1)을 쓴다. 예: n = 5 → 2.132.
  - 이때 L_C = t·σ₀, L_D ≈ 2·t·σ₀ 이다.

### 3.4 DF 산출

**경우 1: 모든 B 시편이 x < L_C (미검출, 예상되는 경우)**

```
DF ≥ A₀,low / L_D
A₀,low = Ā₀ − t(0.95, n−1) · s(A₀)/√n      (A₀의 보수적 하한)
```

- "잔류 Co ≤ L_D µg/cm² (95% 신뢰)이므로 DF ≥ ○○"로 보고한다.

**경우 2: L_C ≤ x < L_Q (검출되지만 정량은 불확실)**

```
DF ≥ A₀,low / x_UCL,   x_UCL = x̄ + t(0.95, n−1) · s(x)/√n
```

**경우 3: x ≥ L_Q (정량 가능)**

```
DF = Ā₀ / x̄
u(DF)/DF = √[(u(A₀)/A₀)² + (u(x)/x)²]
```

### 3.5 계산 예시 (가정값 — 실제 값으로 반드시 교체)

가정:
- 모재 Co 1,500 ppm, Ni 9%
- 분석 층 1 µm → 함께 녹는 모재 7.9 g/cm³ × 1×10⁻⁴ cm = 0.79 mg/cm²
- 따라서 녹은 모재의 Co = 1.19 µg/cm², Ni = 71 µg/cm²
- Co 측정 정밀도 2%, r 불확도 2%

| 항목 | 값 |
|---|---|
| σ₀ ≈ √(0.024² + 0.024²) | 0.034 µg/cm² |
| L_C = 1.645 σ₀ | 0.056 µg/cm² |
| L_D = 3.29 σ₀ | 0.11 µg/cm² |
| A₀ (crud 5 µm, ρ 5.2 g/cm³, Co 5,000 ppm) | 13 µg/cm² |
| **DF 하한** = 13 / 0.11 | **약 120** |

같은 조건에서 분석 층 두께만 바꾸면 다음과 같다.

| 분석 층 두께 | L_D (µg/cm²) | DF 하한 |
|---|---|---|
| 1 µm | 0.11 | 약 120 |
| 10 µm | 1.1 | 약 12 |
| 시편 전체 (1 mm) | 약 100 | 1보다 작아 의미 없음 |

→ **분석 층 두께가 결과를 좌우한다.**

### 5.2 문장 예시

> 제염 후 시편(n = 3) 표면 1.0 µm 층의 과잉 Co는 −0.02 ± 0.03 µg/cm²로, 결정 한계(0.056 µg/cm²) 미만이었다(Currie/ISO 11929 기준 '미검출'). 공정 블랭크(n = 5)에서 구한 검출 한계는 0.11 µg/cm²이었다. 제염 전 crud의 Co 함량은 13.0 ± 0.8 µg/cm²였다(산화막 선택 용해법, 질량법과 일치). 따라서 **DF ≥ 110 (95% 신뢰수준)**이다. 스파이크 회수율은 97%, 불완전 제염 양성대조의 과잉 Co는 2.4 µg/cm²로 검출되어, 본 방법의 판별력이 확인되었다.

## 6. 하지 말아야 할 것

- 시편 전체를 용해해 제염 전후 Co를 빼서 DF를 구하는 것 (원래 문제의 원인)
- 음수나 미검출 값을 0으로 바꾸거나, 결과에서 빼는 것
- "오염도 0", "DF = ∞" 같은 표현
- r을 문헌값이나 다른 히트의 모재로 대체하는 것
- 블랭크·스파이크·양성대조 없이 DF 하한만 제시하는 것
